# Order Tracking and Delivery Issues

Last updated: 2026-11-21

## How to Track an Order
Customers can check order status using their `order_id` (format `SX-XXXXXX`) and the email address used at checkout via the ShopX Support Agent or the Orders page.

## Delivery Attempts
- Carriers (GHN, GHTK, Viettel Post, J&T Express) are assigned automatically and make up to 3 delivery attempts over 3 consecutive business days.
- If all 3 attempts fail, the parcel is returned to ShopX and the order is marked `cancelled`.

## Delayed Shipments
- If an order is more than 2 business days past `estimated_delivery`, customers can request a support ticket (`category: shipping`) for carrier investigation within 24 hours.
