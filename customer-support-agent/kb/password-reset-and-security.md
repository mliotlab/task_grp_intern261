# Password Reset and Account Security

Last updated: 2026-11-21

## Password Requirements
- Passwords must be at least 8 characters long and include at least one uppercase letter, one lowercase letter, and one number.

## Resetting a Forgotten Password
- Click "Forgot Password" on the login page to receive a reset link via email (valid for 15 minutes).
- If no email arrives within 5 minutes, check the spam folder or request a new link (limited to 3 requests per hour).

## Suspicious Activity
- Accounts are temporarily locked for 30 minutes after 5 consecutive failed login attempts.
- If unauthorized access is suspected, customers should request immediate human support (`handoff_to_human`) to freeze the account.
