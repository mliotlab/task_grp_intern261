# ShopX knowledge base

Policy documents of the **fictional** company ShopX, written by the team (20–40 documents, Sprint 1).
The file name (without `.md`) is the `doc_id` used in citations, so keep names stable and kebab-case.

Suggested set:

| Area | Example documents |
|---|---|
| Shipping | `shipping-policy`, `shipping-areas-and-fees`, `international-shipping` |
| Returns | `return-policy`, `refund-process`, `non-returnable-items` |
| Payment | `payment-methods`, `cod-policy`, `installment-payment` |
| Warranty | `warranty-policy`, `warranty-claim-process` |
| Account | `account-registration`, `password-reset`, `privacy-policy` |
| Promotions | `voucher-rules`, `loyalty-program` |

Writing rules: one topic per file, `#` title + `##` sections, concrete numbers (fees, days, limits),
a "Last updated" line at the top. Mix Vietnamese and English documents if you implement FR-09.
