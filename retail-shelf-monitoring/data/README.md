# Data (SKU-110K)

This directory stores the raw **SKU-110K** dataset and the deterministic YOLO-format subset used for training and evaluation. Large binaries, raw images, subset images, and YOLO label files are git-ignored (see `../.gitignore`).

## 1. Dataset Description

- **Name:** SKU-110K (`SKU110K_fixed`)
- **Paper:** Goldman et al., *Precise Detection in Densely Packed Scenes*, CVPR 2019
- **Authors' repository:** <https://github.com/eg4000/SKU110K_CVPR19>
- **Domain:** Densely packed retail store shelves captured from diverse angles, lighting conditions, and store layouts.
- **Full dataset size:** 11,743 images total (**8,219** train / **588** val / **2,936** test), single object class (`object`, mapped to class `0: product` in this project).
- **Project subset (`sku110k-shelf-v2`, `seed: 2026`):** **1,000** train / **200** val / **200** test curated retail-shelf images defined in [`../training/configs/data_subset.yaml`](../training/configs/data_subset.yaml) with curated exclusions in [`../training/configs/sku110k_excluded.csv`](../training/configs/sku110k_excluded.csv).

### License & Terms

SKU-110K is released by the authors (Trax Retail / Goldman et al.) for **academic and non-commercial research use only** (CC BY-NC). In this project it is used strictly for **internal educational use**. Never commit raw images, archives, or redistributed image files to Git.

## 2. Where to Download

Download the official fixed archive **`SKU110K_fixed.tar.gz`** (~11.4–13.6 GB):

- **Direct archive URL:** `http://trax-geometry.s3.amazonaws.com/cvpr_challenge/SKU110K_fixed.tar.gz`
- **Reference page:** <https://github.com/eg4000/SKU110K_CVPR19>

## 3. Where and How to Place the Dataset

Extract `SKU110K_fixed.tar.gz` so that the extracted folder lives at **`retail-shelf-monitoring/data/raw/SKU110K_fixed/`**:

```text
retail-shelf-monitoring/
└── data/
    ├── raw/
    │   └── SKU110K_fixed/                  # ← extract here (git-ignored)
    │       ├── annotations/
    │       │   ├── annotations_train.csv
    │       │   ├── annotations_val.csv
    │       │   └── annotations_test.csv
    │       └── images/
    │           ├── train_0.jpg
    │           ├── val_0.jpg
    │           ├── test_0.jpg
    │           └── ...
    └── sku110k_subset/                     # ← generated by prepare_subset.py
        ├── images/{train,val,test}/        # git-ignored
        ├── labels/{train,val,test}/        # git-ignored
        ├── manifests/{train,val,test}.csv  # deterministic split manifests
        ├── MANIFEST.csv                    # combined subset manifest
        └── dataset_metadata.json           # version, seed, counts, manifest SHA-256
```

### Download & Extract Commands

Run from **`retail-shelf-monitoring/`**:

**Windows (PowerShell):**

```powershell
New-Item -ItemType Directory -Force -Path data\raw | Out-Null
curl.exe -L -o data\raw\SKU110K_fixed.tar.gz http://trax-geometry.s3.amazonaws.com/cvpr_challenge/SKU110K_fixed.tar.gz
tar -xzf data\raw\SKU110K_fixed.tar.gz -C data\raw
Remove-Item data\raw\SKU110K_fixed.tar.gz
```

**Linux / macOS (bash):**

```bash
mkdir -p data/raw
curl -L -o data/raw/SKU110K_fixed.tar.gz http://trax-geometry.s3.amazonaws.com/cvpr_challenge/SKU110K_fixed.tar.gz
tar -xzf data/raw/SKU110K_fixed.tar.gz -C data/raw
rm data/raw/SKU110K_fixed.tar.gz
```

> **Note on nested folders:** Verify that `data/raw/SKU110K_fixed/annotations/annotations_train.csv` and `data/raw/SKU110K_fixed/images/` exist directly under `data/raw/SKU110K_fixed/` (and not nested twice as `SKU110K_fixed/SKU110K_fixed/`).

### Raw Annotation CSV Schema

The `annotations_{train,val,test}.csv` files have **no header row** and 8 comma-separated columns per bounding box:

| Column | Name | Description |
|---|---|---|
| 0 | `image_name` | Image filename inside `images/` (e.g., `train_0.jpg`) |
| 1 | `x1` | Top-left $x$ coordinate (pixels) |
| 2 | `y1` | Top-left $y$ coordinate (pixels) |
| 3 | `x2` | Bottom-right $x$ coordinate (pixels) |
| 4 | `y2` | Bottom-right $y$ coordinate (pixels) |
| 5 | `class` | Class label (`object`) |
| 6 | `image_width` | Image width in pixels |
| 7 | `image_height` | Image height in pixels |

## 4. Build the Deterministic Subset & Run EDA

Once `data/raw/SKU110K_fixed/` is in place, run from `retail-shelf-monitoring/`:

```bash
# 1. Build deterministic subset (1000 train / 200 val / 200 test, seed=2026)
python training/scripts/prepare_subset.py --config training/configs/data_subset.yaml
# or: make data

# 2. Compute and document EDA statistics (boxes/image, resolution, box size distribution)
python training/scripts/eda.py --data-dir data/sku110k_subset --out-md docs/reports/sku110k_eda.md --out-json docs/reports/sku110k_eda.json
# or: make eda
```

This generates:
- YOLO-format images and labels under `data/sku110k_subset/{images,labels}/{train,val,test}/` (git-ignored)
- Reproducible split manifests `data/sku110k_subset/MANIFEST.csv`, `data/sku110k_subset/manifests/{train,val,test}.csv`, and `data/sku110k_subset/dataset_metadata.json`
- EDA report (`docs/reports/sku110k_eda.md` and `docs/reports/sku110k_eda.json`)
